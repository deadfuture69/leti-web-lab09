# Лабораторная 09. Тестирование сервлета

Нужны JDK 21 и Maven 3.9. Из корня проекта выполните `mvn clean test`.
Проект содержит исходный класс GreetingServlet из Lab03 и восемь тестов JUnit 5 с Mockito. Запуск Tomcat для тестов не требуется.

Тесты покрывают параметры инициализации, GET и POST, HTML и UTF-8, валидацию и ошибку записи ответа.
